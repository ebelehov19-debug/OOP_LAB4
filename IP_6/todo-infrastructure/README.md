# PostgreSQL and Redis Infrastructure for Todo App

## Контракт для приложения

### Development окружение
- **Namespace**: `todo-dev`
- **PostgreSQL Host**: `postgres.todo-dev.svc.cluster.local`
- **Port**: `5432`
- **Database**: `todoapp`
- **Redis Host**: `redis.todo-dev.svc.cluster.local`
- **Port**: `6379`
